I'm a geospatial engineer and founder based in Calgary, Canada.
I build software that helps people make sense of location data,
from finding a parcel of land to choosing a neighbourhood.

I co-founded [Maps & Apps](https://www.mapsnapps.org/), an independent
studio building products around maps, location data, and AI.

## What I build

- **[Township Canada](https://www.townshipcanada.com/) and
  [Township America](https://www.townshipamerica.com/)** help people
  locate land from legal descriptions and explore the data tied to it.
- **[PickYourPlace](https://pickyourplace.app/)** helps people compare
  Canadian neighbourhoods using municipal, census, and transit data.
- **[Unmap](https://unmap.dev/)** provides vector maps, geocoding,
  and routing APIs for developers.

I'm also building [Startup OS](https://trystartupos.com/), a system
that gives AI agents shared context, goals, and permissions to help
build and operate software products.

[Explore all our products →](https://www.mapsnapps.org/#products)

## Code and experiments

- [Geocoder evaluation](https://github.com/mepa1363/geocoder-evaluation):
  notebooks for geocoding and analysing address data.
- [Mobility Explorer](https://github.com/mepa1363/mobility-explorer):
  a traffic monitoring platform for analysing human mobility.
- [Amazon Location route planner](https://github.com/mepa1363/amazon-location-route-planner):
  a route-planning example using Amazon Location Service.

## What interests me

I enjoy working through the whole problem: understanding the source
data, building the pipelines and APIs, and making the result useful
through a clear interface.

My background includes a PhD in Geomatics Engineering and developer
advocacy for Amazon Location Service. I work with JavaScript, Python,
SQL, Vue/Nuxt, PostgreSQL/PostGIS, and web mapping tools.
